Architecture Walkthrough — Interactive Visualizations

Two-Stage Filter Pipeline

Videos flow through fast filters (view_count, duration, title, publish_date, description_snippet) before an optional HTTP fetch, then through slow filters (like_count, category, keywords, full_description). Based on _process_videos_generator in fetchers.py.

Pagination & Continuation Token Loop

Channel videos are loaded page-by-page. Each page returns a continuation token used to fetch the next batch via POST /youtubei/v1/browse. Based on _get_raw_channel_videos_generator.

Comment Endpoint Cascading Search

Three search strategies are tried in order to find comment sort endpoints: 1) sortFilterSubMenuRenderer, 2) engagementPanels, 3) continuation tokens. Based on get_sort_endpoints_flexible in comment_api_client.py.

Caching: DummyCache vs SQLiteCache

DummyCache always misses (raises KeyError). SQLiteCache stores entries with TTL-based expiry — expired entries are lazily deleted on read. Based on caching.py.

_deep_get JSON Traversal

Traverses nested dicts/lists using dot-separated keys. Handles list indices with isdigit(). Returns default on any miss. Based on _deep_get in utils.py.
