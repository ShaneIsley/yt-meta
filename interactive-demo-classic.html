Facade Pattern as API Design Philosophy

yt-meta exposes a single YtMeta class that delegates to five specialised fetcher classes. The diagram below shows the full request flow: from the consumer’s method call, through the facade, into the fetcher, through the cache layer, and out to YouTube’s API when needed.

Select a request type and toggle cache behaviour to see how data flows through the system.
